# research/

各AIの調査結果・速報を置く場所。ここにあるものはまだ「カード」ではない。

- `chappy/`：チャッピー（ChatGPT）の一次ソース調査。ファイル名は `YYYY-MM-DD-内容.md`
- `grok/`：Grok の速報。ファイル名は `YYYY-MM-DD-news.md`
- 画面（UI）の調査は、両方とも `YYYY-MM-DD-ui-タスク名.md`。カードの事実ではないので `curation/` には入れず、`docs/tasks/` の判断材料にだけ使う

Claude Code は、ここの内容を CLAUDE.md の手順に従って確認してから `curation/` に反映する。
Grok の速報は、公式ソースで確認できるまで `curation/` に入れない。
