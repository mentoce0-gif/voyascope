報告で「未確認」だったものを、Claude Code が直接確かめた（2026-10-03）：

- **ブラウザから読めるか（CORS）**：GIBS の地図画像（WMTS のタイル）も SWPC の Kp の JSON も、`Access-Control-Allow-Origin: *` を返す。どちらもブラウザから直接読める
- Kp の JSON は `cache-control: max-age=60`。ファイルは3時間ごとより細かく作り直されている（最終更新の時刻から）。値そのものは3時間ごと

## 判断（Claude Code）

- **今日の地球の画像（GIBS、M10）**：ブラウザから WMTS で直接読む形にする。公式が Web の地図ライブラリでの利用を案内しており、CORS も開いていて、Horizons のような「サイトに埋め込まない」決まりはない。画像を自分のサイトに保存して配ることはしない（毎日の画像をリポジトリに溜めないため。読み込み量の上限にも入らない）
- **GIBS の出典**：謝辞の文は「このアプリについて」にそのまま書き、画像のそばには短く「NASA GIBS」と出す。使うレイヤーごとに、NASA 以外のデータでないか（条件が違わないか）を、作るときに確かめる
- **宇宙天気（SWPC の Kp、M11）**：パブリックドメイン。ブラウザから直接でも、Actions で取って配っても使ってよい。どちらにするかは M11 を作るときに決める（おすすめはブラウザから直接。3時間ごとの値なので、ページを開いたときに1回だけ読めば足り、Actions の遅れ（1〜4時間）の影響を受けない）。出典は文字で「Data source: NOAA SWPC」。グラフにしても、NOAA の公式の表示に見せない
- **ロゴ**：NASA・NOAA・NWS のロゴは使わない（RULES の1と同じ）
