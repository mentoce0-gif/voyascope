## 2. 市場の見方（だれが、何を、もう出しているか）

- **公式**：JAXA の「みお」サイトは解説が厚いが、新しいお知らせは 2026-06-04 のファクトシート更新が最後（2026-10-21 確認）。ESA の到着の最新情報は英語。どちらも「いま、どこを回っているか」を動きで見せるものではない
- **関心の大きさ**：ISAS の投稿は「いいね」72、引用元の CNES は125（2026-10-21 時点）。MMX の打ち上げのような大きな山ではなく、日本では静かな出来事。中高生の目に自然には入りにくい
- **空いているところ**：日本語で、①「2機がいっしょに着いて、1か月後に分かれる」流れを動きで見せる、②分かれたあと「2機がどこを回っているか」を毎日見せる、の2つ。ここは公式も報道も手薄
- **VOYASCOPE の強み**：模型（3つの部品）と Horizons の距離をもう持っている。MMX の「いまどこ」の作り方（オープニング・監視モード）を使い回せる
- **弱いところ・気をつけること**：ESA の画像・データは使わない決まり（みおのサイトの写真も ©ESA が多い）。距離は Horizons の ESA の軌道で、分離のあと番号が変わるかもしれない（タスク014）。オーナーの稼働は週数時間で、11/21 まで1か月

→ 大きなページを一度に作るより、**11/21 と 12/9〜10 の2つの山に、小さく1段ずつ**のほうが、関心の波と稼働に合う。
