# 遠くを見る部屋（M7 v0）：体感の検討（2026-10-02）

M6 と並行して進める（2026-10-02 オーナー）。案を出し、オーナーと決めてから画面を作る。
元の方針：[`docs/world-plan.md`](../world-plan.md)（世界は「部屋」で見せる。条件は「視覚の導線と没入できる体験」）、[`docs/sky-families.md`](../sky-families.md) §4（探査機は地球儀に置かない。地球の輪の外は別スケール）。

触って比べる試作：[`far-room-feel.html`](far-room-feel.html)（ブラウザで開く。アプリ本体には入れない）。

## 1. 何を感じてほしいか

帰りに言えること：**「地球の輪の外は、桁が違う」**。

- 月までの距離と、ボイジャー1号までの距離は、数字で書くとどちらも「〜km」で、違いが体に入らない
- 中高生が知っている物差しは「時間」（秒・分・1日）と「スクロール・画面の数」。距離をこのどちらかに置き換える

## 2. 案

試作の数値はすべて**仮**（月・L2・太陽・1光日の目安）。本番の距離は JPL Horizons（C14 の確認後）から毎日取り、光の時間はそこから計算する。推測の値は使わない。

| | 案 | 体験 | 良いところ | 気になるところ |
|---|---|---|---|---|
| A | 距離のはしご | 桁ごとの目盛り（1万km、10万km、…）に探査機の名前を置く。下へ行くほど遠い | 全部が1画面で見渡せる。部屋の地図になる | 対数の目盛りは、それだけだと「桁が違う」が抽象的 |
| B | 光の旅 | 「光を出す」を押すと、地球から光が出て、本当の速さで進む。1.3秒で月、5秒で L2、8分19秒で太陽。ボイジャー1号には「あと23時間…」 | 月までの1.3秒を**実時間で**待つのが、いちばん体に入る。「いまボイジャーに届いている光は、昨日の◯時に地球を出た」と言える | 太陽から先は待てない（早送りが要る） |
| C | 実寸のスクロール | 1px＝1,000km で下へスクロール。月まで約0.4画面、L2 まで約2画面。太陽はこのまま行くと約220画面、ボイジャー1号は約3.8万画面、と数で見せる | 「スクロールしても着かない」が分かりやすい | 長い。月〜L2 から先は数で見せるしかない |

## 3. おすすめ

**A を部屋の地図に、B を見どころにする**（1つの部屋に見どころは1つ）。

- 部屋に入ると A のはしごが見え、名前を押すと詳細（距離・光で何時間・出典）
- 見どころは B の「光を出す」。月までは実時間、その先は「×60」「×3600」の早送りを押して進める。早送り中はいつもその倍率を出す
- C は採らない。ただし「太陽まで約220画面」のような数は、B の補足の1行として使える

## 4. 決めてほしいこと

1. 案（A＋B のおすすめでよいか、B だけ・C も、など）
2. B の早送りの段（×60・×3600 でよいか）
3. 部屋に置く探査機（world-plan の候補：ボイジャー1号・ジェイムズ・ウェッブ宇宙望遠鏡・ベピコロンボ・はやぶさ2。同時に光る名前は最大10）

- 探査機のカード（C12 と同じ形、1機ずつ）
