## 1. 何を感じてほしいか

帰りに言えること：**「地球の輪の外は、桁が違う」**。

- 月までの距離と、ボイジャー1号までの距離は、数字で書くとどちらも「〜km」で、違いが体に入らない
- 中高生が知っている物差しは「時間」（秒・分・1日）と「スクロール・画面の数」。距離をこのどちらかに置き換える

## 3. おすすめ（D を加えて見直し・2026-10-02）

**D を見どころに、A を一覧（地図）にする**（1つの部屋に見どころは1つ）。

- 部屋に入ると D の画面。地表の近くから、上へスワイプで飛ぶ。右上に km・光年・光で何秒、下に通り過ぎた探査機のカード
- B のよいところ（本当の光の速さ）は、D の「光で◯秒」の表示と、月を通るときの1行（「光ならここまで1.3秒」）に入れる。B の画面は作らない
- A は、D の下に置く。**下へスクロールすると、はしご（一覧）がある**（2026-10-02 オーナー決定）。飛ばずに探査機を選びたい人・キーボードや読み上げで使う人のため。押すとその距離まで飛ぶ
- C は採らない。「太陽まで約220画面」のような数は、カードの補足に使える
- 下に物差し（2026-10-02 オーナー案・試作に追加）：「0〜いまの距離」を表し、遠くへ行くほど縮尺が変わる（1目盛り＝1万km → 20億km …）。通り過ぎた場所の印（▼）は左へ押しつぶされ、太陽の先では月も太陽も「0」にくっつく
- 守ること：光より速いのはワープ（作り話）と画面に書く。数字はすべて Horizons の値と出典から。動きを減らす設定では星を流さない（試作で対応済み）
