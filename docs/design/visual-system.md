## 考え方

- **色は製品らしく、数字は計器らしく。** 背景は黒に近い紺、操作は落ち着いた青。時刻・距離・データの日時は JetBrains Mono のまま（「観測端末」らしさはここで残す）
- **色には役割を1つだけ持たせる。** 同じ色を別の意味に使わない
- 走査線（ブラウン管風の横縞）・ノイズ・ちらつき・光る縁取りは使わない

## 色（`web/css/style.css` の `:root`）

| 名前 | 値 | 使うところ |
|---|---|---|
| `--bg` | `#080C14` | 背景 |
| `--surface` | `#18212D` | 操作面（ボタン・入力） |
| `--panel` | `#202B39` | パネル（一覧・詳細・モーダル・下から出るシート） |
| `--text` | `#F3F6FC` | 主な文字・アイコン。見出しや名前の強調も、色ではなく白と太さで |
| `--text-dim` | `#A5AFBE` | 説明・ラベル・選んでいないもの |
| `--accent` | `#5C9DFF` | 操作・選択・リンク・機体の印 |
| `--live` | `#5ED6A4` | ライブ・成功だけ（LIVE の印・運用中の点・軌道データの受信） |
| `--warn` | `#F2BB66` | 警告・注意だけ（運用の知らせ・停止予定・計算できない機体の知らせ） |
| `--line` / `--line-strong` | 灰の半透明 | 枠線・区切り |
| `--ref` | `#A8BCE0` ＋点線 | 参考（公式の発表ではない情報）。いままでどおり |

- 琥珀を「強調」に使わない。機体の金色の箔（MMX のアイコンの胴など、ものの色）は別
- 緑を「押せる」の意味に使わない

## 地球の上の印

- 機体：青い点＋うすい輪。**測位（みちびき）は白**、通信の帯は灰。有人・気象・科学・その他は青（`web/js/families.js`）
- **選んでいる機体：白い輪＋青い点**（2026-10-28 オーナー）
- 軌道の環：白の点線（うすく）。射場：ひし形
- 名前：白・太字、背景に溶けないよう影をつける

## 部品

- 角の丸み：ボタン 12px（`--radius`）、パネル 16px、下から出るシート 20px、表示切替・バッジは丸
- 押せる大きさ：44px（スマホ）
- 主な操作（観測を開始など）：白地に濃い字
- ふつうのボタン：`--surface` 地に白い字
- 選んでいるタブ・表示切替：白地に濃い字（地球の上の列・部屋の帯・一覧のタブ）。詳細の中のタブは青い下線
- 時間のつまみ：青い道（いままで）＋白い丸
- 注意：琥珀のうすい地＋琥珀の丸に「!」
