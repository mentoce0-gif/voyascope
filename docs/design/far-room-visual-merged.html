※非公式ファンメイド作品です。宇宙機関・運用者とは関係ありません。距離と文は VOYASCOPE のカード（出典つき）から写した固定の値です（距離は 2026年10月3日 21時）。

この試作の工夫（Claude 案 × Codex 案）
  • さわり心地は Claude 案：はじく強さで速さが変わり、約1秒で止まる。光より速いと視野が広がり、星が線になって流れる
  • 表示は Codex 案：左に大きな名前と説明、右上に地球からの距離、下に物差し、右下に「その先へ →」、下へスクロールで「遠さにも、階段がある。」
  • 航路は、天体のまわりで曲がる弧をつないだ道。どこもまっすぐ通り過ぎない。点線が、これから進む航路
  • 月・水星・火星・木星では重力でスイングバイ：近づいて、まわりを回り、向きを変えて飛び出す（はじいて通っても、次の場所まで押し出される）
  • 探査機と太陽のそばは「回りこむ」：探査機には向きを変えるほどの重力がないので、スイングバイとは呼ばない
  • 地球は出発のときだけ前に見えて、すぐ後ろへ回る。そのあとは左上の「うしろ」の窓で、小さくなっていく地球を見る（見かけの大きさは本当の値）
  • パーサヴィアランスは火星の地面にいるので、宇宙に浮かべず、望遠の窓で見る
  • 探査機の模型は、公式のページの写真と説明を参考に Codex が作ったもの（far-room-models.js、2026-10-04）。画面の注記は「公式を参考にしたイメージ」だけ（2026-10-04 オーナー）
  • 光と質感：太陽の光らしい白い主光で、模型に影ができる。宇宙の暗さに合わせて、映り込みを少し控えた。火星の地面には、ローバーの影が落ちる
  • ジュノー：木星の重力でスイングバイ。機体は、本当の速さ（1分に2回）で回っている
  • 1光日の輪の手前に、ボイジャー1号（11月18日にここへ届く予定。NASA の予告）。いまの距離の公式の値はまだないので、輪のそばに置いた（2026-10-04）。ボイジャー2号は、いまの距離が分かるまで置かない
  • 「探査機をもっと知る」は VOYASCOPE のカード（出典つき）だけで書いた。Codex 案の詳しい説明は、出典をまだ確かめていないので使っていない
  • 太陽・水星・火星は、地球からの距離の桁がほぼ同じ（1.5億〜2.5億 km）。スイングバイが重ならないように、そこだけ航路をゆっくり進む
  • 動きを減らす設定：星を流さず、傾けず、押した場所へすぐ移る
  • 調整できる値は、ファイルの先頭の TUNE にまとめた
