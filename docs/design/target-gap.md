## 2. 権利を確認済みで、使えるもの

- **写実的な地球（昼の青い地球＋夜の街の明かり）**：NASA の画像・3D 用のテクスチャは、米国では原則として著作権の対象外。教育・情報目的の Web ページで使ってよい。NASA を出典として示し、NASA が推薦しているように見せないこと（[NASA Images and Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/)、2026-09-30 確認）
  - 使うのは NASA の Blue Marble（昼）と Black Marble（夜の明かり）。ファイルの配布ページを確かめてから入れる
  - スマホで重くならない大きさに縮める（目安 2048×1024、数百 KB）
