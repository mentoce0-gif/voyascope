# 「宇宙を見る目」のページの計画（案）

> 2026-10-28 Claude Code 案（オーナーの発案から）。**まだオーナーの OK はない。** `curation/` は変えていない。
> オーナーの言葉：「衛星に搭載されてる機器・ミッションを中高生に分かりやすく伝えるページ」。教える側なら「学生の手持ち図説などを置かせて、そこに行った機器がどんな計器を積み、どんな風に宇宙を"広げ"てきたか」を伝える。
> 形は MMX・アルテミス2号の特設ページに近い、縦に読み進めるページ。

## 1. ねらい

- **1枚で言うこと**：人の目に見える光は、宇宙から届く光のごく一部。衛星や探査機は、電波・赤外線・X線など、それぞれ違う光を見る「目」（観測装置）を積んで、見える宇宙を広げてきた
- **図説とつなぐ**：中高生が手元の図説・教科書を開いたまま読めるように、図説で探せる**ことば**（電磁波・波長・赤外線・X線 など）を各段に置く。図説の図やページ番号は写さない（図説は出版社ごとに違い、図には著作権がある）
- **いまとつなぐ**：その「目」を積んだ機体が、いまどこを飛んでいるかを、VOYASCOPE の地球の画面・遠くを見る部屋で見られる（`?craft=`・`?probe=` のリンク。2026-10-28 に作った）

## 2. 市場の見方（だれが、何を、もう出しているか）

Claude の一般知識による見立てで、今回は確かめていない。作る前に確かめる。

- **公式（JAXA・NASA の機体ごとのページ）**：観測装置の説明はあるが、機体ごとに分かれていて専門的。装置どうしを「どの光を見ているか」で横に並べたものは、日本語では少ない
- **NASA の電磁波の解説**（英語）：波長ごとの解説は厚いが、日本の機体は出てこない
- **教科書・図説**：電磁波の帯の図はあるが、いま飛んでいる個々の機体・装置とはつながっていない
- **空いているところ**：日本語で、①波長のものさしの上に、いま運用中の機体の「目」を並べる、②それぞれが何を見つけたか（広げたこと）を1つずつ、出典つきで、③その機体のいまの位置へ1回で飛べる。この3つを1つにしたもの
- **VOYASCOPE の強み**：機体のカード（出典つき）と、いまの位置（地球のまわり・遠く）をもう持っている。新しく要るのは「装置」の事実だけ
- **気をつけること**：装置の数は多い。全部を載せると図鑑になり、中高生が読み切れない。1機に1つの「目」から始める

## 3. ページの形（案）

| 段 | 中身 |
|---|---|
| ① ヒーロー | 横に長い「光のものさし」（電波 → 赤外線 → 目に見える光 → 紫外線 → X線）。人の目に見える幅だけ明るく、そのまわりに機体の印。「人の目に見えるのは、ここだけ」 |
| ② 目のカード（1機に1枚） | 装置の名前・見る光（波長の帯）・人の目とのちがい・それで分かったこと1つ（公式の発表・出典つき）・「いまの位置を見る ›」 |
| ③ 図説で探すことば | 段ごとに「図説で探してみよう：赤外線・温度」のような短い札。答えは書かず、図説と見比べてもらう |
| ④ おわり | 「宇宙を見る目は、これからも増える」：打ち上げ予定（MMX の装置など）へ |

見た目：遠くを見る部屋・アルテミス2号と同じ配色と字。装置の画像は使わない（JAXA の画像は事前の許可が要る〈`docs/design/image-terms.md`〉）。ものさしと印は自前で描く。

## 5. チャッピーに頼む調査（C40 の案。オーナーの OK のあとで `prompts/src/chappy.md` に足す）

- 対象：上の6機。1回に1機
- 1機ごとに、代表の観測装置を1〜2つ：
  1. 装置の正式名と、運用機関の日本語の呼び方
  2. 観測する光の種類と波長（または周波数）の範囲。公式の数値と単位のまま
  3. 何を測るための装置か（公式の説明の要約と引用）
  4. その装置で分かったこと・できるようになったことを1つ（公式の発表・論文の紹介ページ。日付つき）
  5. 装置の図や写真の利用条件（使わない予定だが、念のため）
  6. それぞれの出典 URL と、引用した原文
- 中高生向けの言い換えは Claude Code がする（チャッピーには事実と原文だけを頼む）

## 6. 決めてほしいこと（オーナー）

1. この形（光のものさし＋1機に1つの「目」）で進めてよいか。名前（仮：「宇宙を見る目」）
2. 最初の6機でよいか（増やす・減らす）
3. 「図説で探すことば」を置くか。置くなら、ことばだけ（図・ページ番号は写さない）でよいか（ルール5：著作権）
4. いつ出すか。急ぐ日はない（出来事の日に合わせる必要がない）。C40 の結果が来てから決める案
