## 2. 市場の見方（客観）

### 2.1 関心の大きさと時期

- **2029年4月は世界規模の山になる見込み**：国連の国際年・ESA と JAXA の探査機・NASA の探査機（存続すれば）が重なる。最接近の前後の数日に関心が集中し、その前（打ち上げ 2028年・到着 2029年2月）に小さな山がある
- **いま（2026年）は谷**：日本語のニュースは協定の署名（2026-05）や H3・DESTINY+ の話のついでに出る程度。検索で来る量は小さいと見る（数字は取れていない。M13 のニュース台帳で数える）
- **日本の切り口は「見える」ではなく「日本が作った部品が行く」になる可能性が高い**：報道では、肉眼で見やすいのはヨーロッパ・アフリカ側とされることが多い。日本から見えるかは未確認（C41）。見えないなら「日本の空で見よう」は使えない。JAXA の TIRI・太陽電池パドル・H3 が日本の主役になる

### 2.2 だれが、何を、もう出しているか

| 行き先 | 強み | 弱み（中高生が日本語でつかむ用に見て） |
|---|---|---|
| NASA Eyes on Asteroids など公式の3D | 正確・動く | 英語・PC 向けで重い・日本の部品は出ない |
| ESA・JAXA の解説ページ | 正確・日本語あり（JAXA） | 記事の形。「いま、どこにいるか」が動いて見えない |
| ニュース・Wikipedia | その日の出来事・網羅 | 「地球をかすめる」「衝突」の見出しが先に立ちやすい。全体の流れは別の記事 |
| X・YouTube の解説 | 入口として強い | 出典が見えにくい。怖がらせる表現が混じる |

### 2.3 VOYASCOPE だけが出せるもの（勝ち筋）

1. **「静止軌道の内側」を、本物の衛星といっしょに見せられる**：地球の画面にはすでに高度の環とひまわり9号（静止軌道）がある。「ひまわりより内側を、340m の岩が通る」は、文字の要約や公式の3Dにはない絵。これが一番の差
2. **日本の部品が主役の「これまで→これから」**：H3 で打ち上げ → 到着 → 20km→1km→5km で見守る → 最接近。MMX の「いまどこ」と同じ形で作れる
3. **事実ごとの出典と「おそれはない」の明記**：怖がらせる見出しが多い出来事ほど、出典つきの落ち着いた1枚に価値がある（M13 の「速報で勝負しない」と同じ）

### 2.4 負け筋・気をつけること

- **早く作りすぎる**：2029年まで2年半。いま大きく作ると、出来事の前に古くなる（予定の変更・OSIRIS-APEX の行方）。オーナーの稼働は週数時間
- **怖がらせる・ゲームにしすぎる**：「地球防衛」はSFや軍事の連想を呼びやすい。中高生向けには、公式の言い方（プラネタリーディフェンス／惑星防衛）と「衝突しない」をはっきり出す（ルール2の精神。ことばの選び方は 5. でオーナーに）
- **画像**：ESA の画像は使わない決まり（みおと同じ）。JAXA の図も利用条件の確認が要る（ルール5）。模型はコードで描く
- **データ**：アポフィスの位置は JPL Horizons（または SBDB・CNEOS）。JPL SSD の許可（C14、2026-10-04）は探査機の距離の使い方として出したもの。小惑星の位置・最接近の数値も同じ扱いでよいかは、オーナーの確認が要る（ルール5）

→ **いまは「一言ページ＋出来事のカード」で小さく置き、ニュースが出るたびに直す。大きな画面（ランデブーと最接近）は 2028年の打ち上げから 2029年4月に向けて作る。**
