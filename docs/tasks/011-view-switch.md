# タスク011：地球の上の表示切替（すべて／日本のみ／衛星のみ／打ち上げ予定のみ）

ロードマップ：[`docs/roadmap.md`](../roadmap.md) の M6「見た目・カードの次の手」。方針の記録は [`docs/sky-families.md`](../sky-families.md)（冒頭と §8）。

## きっかけ（2026-10-02 オーナー）

> 表示切替ボタンが標準画面に欲しい。「すべて」「日本のみすべて」「衛星だけ」「打ち上げ予定のみ」くらいを切り替えられるようにしたい

Claude Code から聞いて、オーナーが決めたこと：

- 「日本のみ」に ISS を**入れる**（ISS のカードの「運用」に JAXA が入っている）
- 置き場所は**地球の上**（上のバーのすぐ下に4つ並べる。PC もスマホも同じ場所）
- **一覧も合わせる**（打ち上げ予定のみ → 一覧も予定タブ、日本のみ → 一覧も日本のものだけ。予定タブを押すと打ち上げ予定のみ）

## 作ったもの

- **表示切替**（`web/js/view.js`・`#view-switch`）：押しているものはミント色。選んだ表示はブラウザにだけ覚える（`localStorage`。読めなければ「すべて」）

| 表示 | 地球に出すもの | 一覧 |
|---|---|---|
| すべて | 機体・公式の予定の射場・世界の打ち上げ（参考）の射場 | 機体（タブはそのまま） |
| 日本のみ | 日本の機体・日本の予定の射場・日本の射場からの打ち上げ（参考） | 日本の機体（見出しは「注目・日本のみ」）。予定タブも日本のものだけ。上の「次の出来事」も日本の予定 |
| 衛星のみ | 機体だけ | 機体 |
| 打ち上げ予定のみ | 射場のピンだけ（公式・参考） | 予定タブ |

- **日本の決め方**（事実だけで決める）
  - 機体：カードの「運用」（出典つき）に日本の機関（JAXA・気象庁・内閣府・環境省・国立環境研究所・国立天文台 など）が入っている
  - 予定：`regions` に `japan` がある
  - 世界の打ち上げ（参考）：射場が日本にある
  - いまの7機はどれも日本の機関が運用に加わっているので、当面「日本のみ」と「すべて」の差は予定と打ち上げだけ。世界の機体（天宮・ハッブルなど、M5 v1）を足すと差が出る
- **押すと見どころへ地球が向く**：日本のみ → 日本、打ち上げ予定のみ → 次の打ち上げの射場（一覧の先頭と同じく公式の予定を先に。いまは種子島の MMX）。追尾中は動かさない
- **ほかの表示との関係**
  - 表示切替は「組み合わせのひな形」。押すと、凡例（PC）やスマホの一覧のタブで消していた家族も全部に戻す。そのあと凡例で消すのは自由
  - 一覧の予定タブを押すと「打ち上げ予定のみ」、予定タブから家族のタブ・観測へ移ると「すべて」に戻る
  - 表示切替で、一覧のタブは「すべて」に戻る（観測タブはそのまま）
- **世界の打ち上げ（参考）のピン**：これまでは予定タブのときだけだったのを、表示切替に従うようにした（すべて・打ち上げ予定のみで出す。日本のみは日本の射場だけ）
- **射場の名前の重なり**：機体の名前と、日付の早いピンの名前を優先し、重なったピンの名前を隠す（ひし形は残る。マウスを乗せる・キーボードで選ぶと出る）。選んでいるピン・一覧で指しているピンの名前は必ず出す
- **「現在の地球」の表示**：「7機（有人・気象・科学・測位）・射場 5か所」のように、射場の数も出す
- **配置**
  - PC：一覧の右、上のバーのすぐ下。「現在の地球」の枠はその下へ。幅の狭い PC（901〜1180px）で詳細を開いているあいだは隠す（詳細のパネルと重なるため）
  - スマホ：上のバーのすぐ下に左寄せ。押せる範囲は44px。シートを全部の高さに広げても隠れないように、シートより上に置き、シートはその下から始める。幅380px未満では短い名前（すべて・日本・衛星・打ち上げ）。読み上げは長い名前のまま
- 「このアプリについて」に、表示の切り替えと「日本のみ」の決め方を書いた

## 確かめたこと

- テスト（`tests/view.test.mjs`、4件）：4つの表示の名前、日本の機体（いまの7枚のカードがすべて日本に入る・入らない例）、日本の予定と射場、それぞれの表示で出すもの
- ブラウザ（Chromium、時刻を 2026-10-02 15:00 日本時間に固定）
  - PC 1440×900：4つを順に押す → 地球の機体とピンの数・一覧・見出し・予定の見出しが切り替わる。日本のみで地球が日本（北緯36° 東経138°）へ、打ち上げ予定のみで種子島へ向く。予定タブ⇄表示切替の連動、凡例で消した家族が表示切替で戻る、キーボード（Enter）、覚えた表示で始まる
  - 幅1000px：詳細を開くと隠れ、閉じると戻る
  - スマホ 390×800：一覧を全部に広げても押せる（シートは表示切替の下から）。360・320px：短い名前ではみ出しなし
  - コンソールのエラーなし
- 画面：[`docs/screenshots/view-switch/`](../screenshots/view-switch/)

## やらないこと（このタスクでは）

- 世界の機体（天宮・ハッブル）を足すこと：M5 v1（名前の確認 C6 とカードのあと）
- 表示の種類を増やすこと（国ごと・家族ごとの細かい切り替えは、PC の凡例とスマホの一覧のタブのまま）
