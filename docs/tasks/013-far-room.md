# タスク013：遠くを見る部屋（M7 v0）

ロードマップ：[`docs/roadmap.md`](../roadmap.md) の M7 v0。体感の設計：[`docs/design/far-room-feel.md`](../design/far-room-feel.md)（2026-10-02 オーナー決定：「光になって飛ぶ」を見どころに、下へスクロールすると「距離のはしご」。下に縮尺の変わる物差し）。
今回は、JPL の許可が要らない部分と、ジュノー以外で作る（2026-10-03 オーナー）。ジュノーは C17 で運用中と確かめて、2026-10-04 に足した。JPL SSD からは 2026-10-04 に了承の返事があった（下の「あとでやること」）。

## 作ったもの

- **入口**：地球の上の表示切替の右に「遠くを見る ›」（PC）。スマホは表示切替の下の右。ほかの部屋へ行くボタンなので、表示切替（ミント）と分けてアンバーにした。押すと画面いっぱいの部屋が開く
  - 閉じ方：「地球へ戻る」・Esc・ブラウザの「戻る」。`#far` つきの URL で開くと、「観測を開始」のあとすぐに部屋が開く
  - 部屋の部品は、入口にマウスを乗せた・指で触れた・フォーカスしたときから読み始める（起動では読まない）。開いているあいだは地球の描画を止める
- **光になって飛ぶ**：下へスワイプ（PC はホイールを奥へ回すか ↑ キー）で遠くへ、上へで戻る（2026-10-04 オーナー：スワイプの向きを逆にした。はじめは上へスワイプで遠くへ）。はじく強さで速さが変わり、約1秒で止まる（試作と同じ）
  - 右上：地球からの距離（km・光年）、光で何秒、速さ。光より速いときは「ワープ中：光の◯倍（作り話）」
  - 通り過ぎた場所のカード（月・ウェッブ・太陽・ベピコロンボ・パーサヴィアランス・ニュー・ホライズンズ・1光日）。探査機は「カードを見る」でくわしいカードへ
  - 下の物差し：0〜いまの距離。遠くへ行くほど縮尺が変わり、通り過ぎた場所（▼）は左へ押しつぶされる
  - 動きを減らす設定では、星を流さず、押した場所へすぐ移る。キーボード：↑↓・PageUp／PageDown・Home（地表へ）
- **距離のはしご**：「10万 km〜」から「100億 km〜」までの段（下へ行くほど10倍遠い）。いちばん上に「地上」（打ち上げ前の MMX）。名前を押すと、その距離まで飛ぶ。いまの距離を出せない4機は「いまの距離は準備中」に並べ、カードは見られる
- **探査機のカード**：いま・状態（確かめた日つき）・距離（どうやって出したか）・予定（日本時間と残り）・任務・運用・打ち上げ。事実ごとに「出典」のリンク。公式のページ
- 部屋のいちばん下に「距離の出し方」と、非公式ファンメイドの注記。「このアプリについて」にも部屋の説明とライブラリを足した

## 載せた探査機と、距離の出し方

| 探査機 | 距離（2026-10-03 21:00） | 出し方 |
|---|---|---|
| ジェイムズ・ウェッブ宇宙望遠鏡 | 約150万 km | NASA の説明の目安（L2）。**その日の距離ではない**と画面に書く |
| ベピコロンボ（みお） | 約1.71億 km | 水星までの距離をブラウザで計算。水星に着く途中なので目安 |
| パーサヴィアランス | 約2.47億 km | 火星までの距離をブラウザで計算（火星の地面にいる） |
| ニュー・ホライズンズ | 約95億 km | NASA の日付つきの値（2026-06-23、冬眠から目覚めたと確かめた日）。いまの距離ではない |
| 火星衛星探査機（MMX） | 地上 | 打ち上げ前（10/20 予定）。はしごの「地上」の段 |
| パーカー・ソーラー・プローブ、はやぶさ２、ボイジャー1号・2号 | 準備中 | JPL Horizons の値を取る仕組みを作ってから出す（2026-10-04 JPL SSD が了承） |

- くらべる目安：月・太陽（ブラウザで計算）、**1光日**（光の速さ × 24時間＝約259億 km。NASA の「25.902 billion km」と同じ）。1光日の段とカードに「ボイジャー1号は 11月18日 19:16（日本時間）、ここに届く予定（NASA）」
- 月・太陽・惑星は、部屋を開いた時刻の位置から計算し、開いているあいだは1分ごとに計算し直す
- 光の時間は、目安の値・日付つきの値には「約」を付けて丸める（もとの値の細かさに合わせる）

## データ

- `schema/probe.schema.json`：探査機カードの形（新規）。`distance` の書き方は5つ：`planet`（いる惑星までの距離を計算。惑星にいることを確かめた出典つき）／`typical`（公式の目安の値）／`dated`（日付つきの公式の値）／`pending`（準備中）／`on_earth`（打ち上げ前）。キャッチコピーなどの創作の項目は持たない
- `curation/probes/`：10機（新規）。C16（チャッピー）の報告を Claude Code が出典のページと照合し（`research/verification/2026-10-03-c16.md`）、カードの文は出典に書かれていることだけで書いた
  - ジュノー（2026-10-04 に追加）：C17 の報告を照合した（`research/verification/2026-10-04-c17-c18.md`）。状態は、2026年5月1日に衛星テーベを撮った記録（NASA Photojournal）。いま・任務などは、NASA のジュノーのページ（2026-07-04 の更新で「木星を回って10年」）。距離は木星までの距離（計算）。運用を終える予定の日は書かない（公式のページは「2025年9月まで」のままで、新しい日付が見つからない）
  - C16 の報告から直したもの：ウェッブの運用機関（報告は STScI の求人のページが出典だった → NASA のページの「Partners NASA/ESA/CSA」）、ニュー・ホライズンズの値の日付（報告の 6/24 は写真の説明の日付。本文では、冬眠から目覚めたと確かめた 6/23 に同じ「約95億km」と書いている → 6/23 にした）、パーサヴィアランスの運用（JPL の記事の「JPL … manages operations of the Perseverance rover」）
  - 報告にあった次の予定（`next_event`）は、すでにある予定（`curation/events`）の id で指す（ベピコロンボ2件・はやぶさ２・MMX・ボイジャー1号）
- `scripts/validate.mjs`：探査機（`probes`）を足した。指している予定がないもの、打ち上げ前なのに地上以外の距離を書いたものを落とす
- `web/data/probes.json`：`npm run sync:web` で作る

- **パーカー・はやぶさ２・ボイジャー1号・2号のいまの距離**：JPL Horizons の数値を自分のサイトに出すには許可が要る（C14）。オーナーが問い合わせ（2026-10-03）、**2026-10-04 に返事：書いた使い方で問題ない**（[記録](../../research/verification/2026-10-03-c14.md#jpl-ssd-とのやりとり記録)）。作るときの決まり：
  - 丸めた値・「Horizons の計算値」・取得日をつけて出す。いまの通信の値とは書かない
  - 出典：`Solar System Dynamics. (Downloaded 年, 月, 日). Horizons System. https://ssd.jpl.nasa.gov` に、日本語の説明を添える
  - 軌道のもとのデータを出した機関（Horizons の説明（datasheet）にある ESA・JAXA など）を、距離のそばに書く。説明が変わったら知らせて、確かめてから直す
  - 取り方：Fair Use に合わせ、Actions で週1回、1件ずつ。1回で先の数週間ぶん（1日ごと）をもらって使い回す。ブラウザから呼ばない
  - パーカーは問い合わせの例に入っていなかった（含めるかはオーナーの判断待ち）
- ボイジャー1号・2号の公式ページにある古い日付つきの値（2024年・2017年）は使わない（いまの距離と誤解されるため）
- 惑星（木星・土星など）の目印は置かない（イメージ図どおり、くらべる目安は月と太陽）
- 音・振動はなし（体感の §4-2 の判断待ち）
- MMX の打ち上げ（10/20）のあとは、カードの状態・いま・距離を直す（G4 で公式の発表を確かめてから）

## ライブラリを1つ足した

- **Astronomy Engine 2.1.19（MIT License）**：月・太陽・惑星の位置。使う4つ（`GeoVector`・`Body`・`MakeTime`・`KM_PER_AU`）だけを esbuild でまとめて `web/vendor/astronomy.min.js` に置いた（gzip 後 約21KB、ライセンスの全文はファイルの先頭と `astronomy-engine.LICENSE.txt`）。部屋を開いたときだけ読む

- `package.json` の依存は増やしていない（ブラウザ用に同梱しただけ。作り直し方は `web/vendor/README.md`）
