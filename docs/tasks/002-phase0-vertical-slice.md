# タスク002：Phase 0 ── ISS 1機のバーティカルスライス

## 目的

「地球＋ISS 1機＋キャラカード＋時間早送り」だけで、VOYASCOPE の見た目と手触りを確かめる。
機能を増やすことより、オーナーが「見て楽しい」と感じる仕上がりを優先する。

## 作るもの

`web/` に静的サイトを作る（ビルドツールなし、HTML/CSS/JS のみでよい）。

1. **起動画面**
   - VOYASCOPE のロゴ表示。ブラウン管（キネスコープ）風の走査線とわずかなノイズ
   - サブタイトル「今、宇宙を旅する者たち。」
   - 「※非公式ファンメイド作品です」を必ず表示
2. **地球**
   - globe.gl（three.js ベース）で3D地球を表示
   - リアルな写真調より、観測モニター風の簡素な表現を優先（紺地に mint の線など）
3. **ISS の現在位置**
   - satellite.js（SGP4）でブラウザ内計算
   - 軌道データ（TLE/OMM）は CelesTrak から**1回だけ手動で取得**し、`web/data/iss-tle.json` に保存する。取得日時をファイルに記録する
   - 自動取得は Phase 1 で、CelesTrak の利用条件をチャッピーが確認してから行う
   - 画面に「軌道データ取得：◯月◯日」を表示する
4. **キャラカード**
   - ISS をクリック／タップすると HUD 風のカードが開く
   - データは `examples/spacecraft/iss.json` を読む
   - 出典が TODO の項目があるので、カードに「見本・出典確認中」の表示を必ず出す
   - ステータスのゲージとランク（S〜C）は、数値から自動で計算する。閾値は `config/rank-thresholds.json` に仮の値で作る（手で盛らない）
   - lv2 公式リンク、lv3 生データリンク（CelesTrak は norad_id から自動生成）を表示する。公式リンクが TODO の間はリンクを無効にしておく
5. **時間早送り**
   - スライダーまたはボタンで ×1 / ×60 / ×600 程度
   - 「現在時刻に戻る」ボタン

## 見た目

- 配色：navy（背景）／ mint（計器・線）／ amber（強調・ランク文字）
- フォント：Zen Kaku Gothic New（本文）、JetBrains Mono（数値・計器表示）。Google Fonts から読み込む
- 中高生がすんなり読める文章。漢字はふつうに使ってよいが、専門用語には短い説明を添える
- スマホでも崩れないこと

## やらないこと

- ISS 以外の衛星（Phase 2）
- 飛行士カード・チームカードの表示（データが出典確認済みになってから）
- GitHub Pages へのデプロイ（private の間は使えないため、ローカルプレビューのみ）
- `curation/` へのデータ追加

## 完了条件

- `npx serve web` などでローカル表示でき、ISS が地球上を動いている
- ISS をタップするとカードが開き、「見本・出典確認中」が表示される
- 早送りで ISS が約90分で地球を1周する様子が見える
- 非公式ファンメイドの表記が起動画面とカード画面のどちらからも確認できる
- 作業はブランチ `feature/phase0` で行い、PR にスクリーンショットを添える
