# タスク005：M3 ── 今夜・頭の上

ロードマップ：[`docs/roadmap.md`](../roadmap.md) の M3。

## 目的

`docs/sky-families.md` の「開く理由」：**日本の今夜の天井**。
県を選ぶと、ISS が次にいつ・どの方角から見えるかが分かるようにする。

## 作るもの

1. 都道府県を選ぶ（47）。位置情報は使わない。選んだ県はブラウザにだけ保存する
2. ISS の見える通過を、この先5日間で最大3件
   - 見える条件：高さ10°以上／空が暗い（太陽が地平線の6°より下）／ISS に日が当たっている
   - 「今夜 19時10分ごろ」「西から南へ・約4分」「いちばん高いとき：低い（南西の空、約23°）」
   - 地点は県庁あたりの代表点。これより細かくしない
3. 空の図（上が北・右が東、中心が頭の上）で通り道を矢印で描く。これが「方位の表示」
4. 「この時刻の地球を見る」：タイムラインをその時刻の1分前へ動かし、ISS を追尾する（+24時間以内のとき）
5. 注意書き：ISS は明るいので街中でも見えることがある／ほかの衛星は街の明かりの下ではほとんど見えない／時刻と方角は目安で、雲は考えていない

## やらないこと

- 位置情報（GPS）の利用、市町村単位の予報
- ISS 以外の通過（M2 の機体は、ほとんど肉眼では見えない）
- 天気予報との連携

## 完了条件

- `npm test` が通る（太陽の位置・地球の影・方角のことば・通過の条件）
- 県を選ぶと通過が出て、再読み込みしても県が残る
- 「この時刻の地球を見る」で、ISS が日本の近くにいる時刻へ移る
