# タスク006：M2 ── 日本の第一棚

ロードマップ：[`docs/roadmap.md`](../roadmap.md) の M2。

## 目的

`docs/sky-families.md` の第一棚（名前で呼べる日本の公的な衛星）を、出典を確かめたカードとして地球に置く。
「低軌道は流れ、静止軌道は留まる」を、実際の機体で見せる。

## 作るもの

1. チャッピー C12 の結果（`research/chappy/2026-09-30-c12-*.md`）の引用を、公式ページで確かめる
   - 結果は `research/verification/2026-09-30.md`
2. 確かめた事実だけで `curation/spacecraft/` にカードを作る（`npm run validate` を通す）
   - ひまわり9号・みちびき6号機・みちびき2号機・だいち4号・いぶきGW・ひので
3. `config/orbits.json` に NORAD 番号を足し、軌道を自動取得する（この順に「注目」一覧に並ぶ）
4. アプリ：カードは `curation/` を優先して読む。見本（`examples/`）のカードだけ「見本・出典確認中」を出す

## やらないこと

- ISS カードの出典（C2〜C4 待ち）と乗員（C10 待ち）
- 「運用中かどうか」の項目（スキーマに足すかはオーナーが判断）
- 機体の線画（ISS 以外）

## 完了条件

- `npm run validate` と `npm test` が通る
- 7機が一覧と地球に出て、静止軌道の2機（ひまわり9号・みちびき6号機）が早送りしても同じ場所にとどまる
- 第一棚のカードには「見本・出典確認中」が出ない
