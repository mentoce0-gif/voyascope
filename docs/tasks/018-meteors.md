# タスク018：流星群（今夜・放射点の方角と高さ）

きっかけ：オーナー「流星群の情報をうまく VOYASCOPE に反映できないか」「トライアルとして、本日ある？と X であった流星群がどのあたりを通る予定かを表したい」（2026-10-08）。

## 方針

- 「見え方予報」や天気・中継は、公式や既存のサービスへ任せる（作らない）。VOYASCOPE は「選んだ県で、今夜、放射点がどの方角・高さにあるか」と月明かりを、ブラウザで計算して見せる
- 極大の日時と放射点（赤経・赤緯）は、公式（国立天文台を最優先。なければ IMO）で確かめてから `curation/events/`（`kind: "meteor"`・`radiant`）に入れる。調べるのはチャッピー（C20）。X は、きっかけとしてだけ使う
- 1時間あたりの数は、出すなら必ず条件（「空の暗い場所で」など）と一緒に。期待させすぎない

## 作ったもの（トライアル）

- `web/js/meteors.js`：放射点の方角・高さ（satellite.js の恒星時で計算）、月の位置と明るい部分（簡易式）、空が暗いあいだ（太陽が −6° より下）を10分ごとに見る
- 「今夜」の画面：極大の前の日から、一覧から消えるまで、流星群の欄を出す（極大・出典・ことばでの説明・空の図（1時間ごとの点、3時間おきに時刻）・月・注意）。県を選んでいなければ案内だけ
- 「次の出来事」：種類「流星群」
- スキーマ：`kind` に `meteor`、`radiant`（`kind` が `meteor` のときだけ）
- テスト：`tests/meteors.test.mjs`
- 画面：`docs/screenshots/meteors/sp-390-trial.png`（照合前の仮のデータで撮った見本。本番には出していない）

## 地球のまわり：ちりが近づいてくる様子（2026-10-08 オーナー「ISS のように『どう飛んでいく』という方向を、地球周辺の見える部分に光点で近づいてきている様子を映してほしい」）

- 流星群のちりは、放射点の方向から平行に地球へ向かってくる。放射点の側の半球の大気（高さ約100km）に飛び込んで、流れ星になる。これを光点で描く（`createStream`・`radiantDirection`）
  - 粒（水色）と短い尾で、進む向きを見せる。大気に飛び込んだところが光る（琥珀色）
  - 放射点の方向は、観測時刻の恒星時で地球に固定した向きに直す。早送りすると、地球が回って、日本が夕方にちりの来る側へ入っていくのが見える
  - 印「（流星群名）のちりが来る方向〔イメージ〕」を、放射点が真上になる地点の上に出す。押すと詳細が開き、ちりが降ってくる様子を斜め横から見る向きに地球を回す
- **数・速さ・距離はイメージ**（実際のちりはずっと小さく、ずっと多く、ずっと速い）。印に「イメージ」と書く
- 出すのは「すべて」の表示で、今夜の欄と同じ期間（極大・見ごろの前の日から）。動きを減らす設定では止める
- 画面：`docs/screenshots/meteors/pc-1440-stream.png`

## しくみの図（平面）と、時間に合わせたちり（2026-10-08 オーナー「出典を記載して平面図記載」「時間と自転を踏まえて経過するように」）

- 詳細の欄に「しくみ：どうしてりゅう座から降ってくるの？」（今夜の欄の「しくみの図を見る」から開く）
  - ① 太陽を北から見た図：地球の通り道と、母天体 21P の通り道（JPL SBDB の軌道要素で計算）・ちりの帯（イメージ）。黄道より南は点線。10/8 の地球の位置（簡易式）と、通り道が黄道を横切る点（約1.01 au）がほぼ重なる。MOID 0.017758 au（JPL）。彗星そのものの位置は描かない（2017年の元期の要素から9年先を2体問題で出すと、木星の影響で大きくずれるため）
  - ② りゅう座のあたりの星（IAU の星名一覧、J2000）と放射点（AMS）。線は頭の一部 β–γ–ξ だけ（イメージ）。上が北・左が東（見上げた向き）
  - つなぐ説明は国立天文台「流星群とは」。りゅう座は「ちりが来る向き」で、彗星がそこにあるわけではない、と書く
  - JPL・IAU の数値は、個別の利用条件が見つからないまま、出典を書いて使う（2026-10-08 オーナー判断）
- 時間：ちりは出現期間（`active`。国立天文台の表 10/6〜10/10）のあいだだけ降る。タイムラインで外へ出ると止まる。自転：放射点の向きを観測時刻の恒星時で地球に固定した向きに直しているので、時間を動かすと地球が回り、ちりの当たる半球が移る
- ちりの粒は 140 → 240（イメージ）
- 画面：`docs/screenshots/meteors/story-draconids.png`

## ちりの見た目（2026-10-08 オーナー「角砂糖がゆらいでいるだけに近い。よりチリ的な表現（光がゆらいで、消える）にできないか」）

- globe.gl の particles（四角い点）をやめ、地球の上に透明なキャンバスを重ねて描く（`globe.getCoords`・`getScreenCoords` で画面の位置に。カメラから見て地球の向こうにある粒は描かない）
- 粒：丸くぼけた小さな光。現れるときにふわっと明るくなり、1つずつちがう速さで瞬く。来た向き（放射点の側）に淡い尾
- 流れ星：大気の高さで光り、進む向きに短い筋をのばしながら、0.9秒ほどで暗くなって消える（明るさは残り時間の2乗で落とす）
- 画面：`docs/screenshots/meteors/pc-dust-closeup.png`

## 流星群のポインタ（2026-10-08 オーナー「詳細が『イメージ』のところだと分かりにくい。矢印の位置を既存のマーカーと別表現でポインタで置いて、そこを詳細表示のトリガーに」）

- ちりが来る方向（放射点が真上になる地点の上空、地球の半径の 0.35 倍）に、点線の輪（琥珀色・ゆっくり脈打つ）と、地球へ向かう矢印（画面の上での向きを毎回計算）のポインタを置く。機体の丸・射場のひし形とは別の形
- 横に「（流星群名） 詳しく ›」のボタン。押すと詳細（しくみの図）を開き、地球を斜め横から見る向きに回す。「ちりの来る方向（イメージ）」は小さな注記にして、押すところと分けた（スマホでは注記を隠す）
- 真正面から来る向きのときは矢印を隠して、輪の真ん中を光らせる
- 画面：`docs/screenshots/meteors/pc-pointer.png`
