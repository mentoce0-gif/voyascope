# タスク008：「いま、どこの上？」

ロードマップ：[`docs/roadmap.md`](../roadmap.md) の「見た目・カードの次の手」。

## きっかけ

カードの「いま」は緯度・経度・高度だけ。「いまどこの上か」を書いた方が面白い（2026-10-01 オーナー）。

## 作るもの

- 詳細の「いま」に、国か海の名前を出す：「**中華人民共和国**の上　北緯 44.6°　東経 85.8°　高度 429 km」
- 見つからないとき（海岸や国境の近くの小さなすき間）は名前を出さず、これまでどおり座標だけ（推測で名前を出さない）

## データ

- Natural Earth v5.1.2（パブリックドメイン。https://www.naturalearthdata.com/about/terms-of-use/ ）
  - 国：`ne_10m_admin_0_countries_jpn`（**日本の立場**の境界。`NAME_JA`）
  - 海：`ne_50m_geography_marine_polys`（`name_ja`）
- `scripts/build-places.mjs` で取得し、線を約11km（0.1度）に間引いて `web/data/places.json` に書く（475KB、圧縮で約134KB）。生成物をコミットする
- アプリは「観測を開始」のあとに読み込む。読めなくても座標は出る

### 境界と名前（判断したこと）

標準の版は、実際に支配している側で線を引いている（択捉島＝ロシア、クリミア＝ロシア、西サハラ＝モロッコ）。中高生向けの日本のアプリなので、日本の立場の版を使った。

| 地点 | 標準の版 | 使った版（日本の立場） |
|---|---|---|
| 択捉島 | ロシア | 日本 |
| クリミア | ロシア | ウクライナ |
| 西サハラ | モロッコ | 西サハラ |
| 北キプロス | 北キプロス・トルコ共和国 | キプロス |
| 台湾 | 中華民国 | 中華民国 → **台湾**に差し替え（オーナー確認待ち） |

- 国後島・竹島・尖閣諸島は、間引いた線では島が小さくて名前が出ない（座標だけ）
- 南極は、データの名前どおり「南極大陸」

## 確かめたこと

- テスト（`tests/places.test.mjs`）：東京・札幌・沖縄本島＝日本、択捉島＝日本、クリミア＝ウクライナ、太平洋・インド洋・大西洋・日本海、経度が±180をこえても同じ
- ISS の1日分の軌道（1分ごと1440点）：名前が出ないのは 0.7%（海岸の近く）。1回の計算は約0.05ms
- 静止衛星：ひまわり9号＝太平洋の上（東経140.8°）、みちびき6号機＝インド洋の上（東経90.5°）

## やらないこと

- 一覧や地球の上のラベルに地名を出すこと（まず詳細の「いま」だけ）
- 都市名・県名（データが重くなる）
