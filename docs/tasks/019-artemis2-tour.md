# タスク019：アルテミス2号に乗ってみる（試作）

きっかけ：オーナー「独自性がないので、より追体験型のモデルを構築してください」「地球〜月を周回しているアルテミスに触れればアルテミスの視点になれるモード（アルテミスが見ていた様子の『ような』視界、航路の通り月の裏側を回り地球へ帰る）。これはワープではなく、数分間アルテミスに搭乗する。画像を数枚参考に、おおよその再現をする」（2026-10-08）。
「3〜4分・写真はリンク」の方向と C22 の依頼文は OK。「月の写真ほんちゃんは NASA のページリンクから。このページはあくまでその画像を参考にしたツアーというていで」（2026-10-08 オーナー）。

## 方針

- 写真はページに載せない。場面ごとに「この場面の本物の写真」の説明と、NASA のページへのリンクを出す（URL は C22 のあと公式で確かめて入れた）
- 窓の外は、写真を参考にした「〜のような眺め」（コードで描く）。写真そのものではないと、ページの下にいつも書いておく
- 通り道ははじめ、地球と月の重力から計算した仮の道（見本）にしていた。2026-10-09 に NASA の軌道データ（エフェメリス）に置きかえた（下）
- 日付・時刻・写真の説明などの事実は、C22 の報告を照合してから入れる（2026-10-09 に入れた。下の「C22 の結果を入れた」）
- 置き場所：`web/tour/artemis2/`（はじめは `noindex`・リンクなし。2026-10-09 に公開し、遠くを見る部屋の月の停留所からつないだ）

## C22 の結果を入れた（2026-10-09）

C22（チャッピー、2026-10-09）の報告を、Claude Code が NASA の公式ページで照合して入れた（照合の記録：voyascope-research の `research/verification/2026-10-09-c22.md`）。

- **場面の順番を本物に合わせた**：地球の入り（4/6 午後6時41分 EDT）→ 月の裏側・通信がとだえる（約40分）→ 月にいちばん近づく → 地球の出（午後7時22分）→ 日食（午後8時35分ごろから。皆既は54分近く）。試作では日食を地球の出の前に置いていたので直した
- 見本の道のりの最接近の高さを本物に合わせた（→ 同じ日に、本物の軌道データに置きかえた。下）
- **写真の欄**：地球の入り・月の裏側（ヴァヴィロフ・クレーター）・地球の出・日食（金星）の4つ。説明は NASA の説明文から（日食は、金星の写った写真の説明だけ。土星・火星の写った別の写真の説明は混ぜない）。リンクは NASA のページ。写真はページに載せない
- タイムライン：4/2 出発・4/7 月の裏側・4/11 帰還（日本時間）。おわりの画面に NASA の写真ページへのリンク3つ
- 地球照（地球で照り返した光）で、月の夜の側がうっすら見えるようにした
- 乗っている時間は約4分（230秒）になった

## 本物の軌道データにした（2026-10-09）

オーナー（2026-10-09）「広く教育用の使用を認める文があり、関連性を示唆するものがなければ利用について許可は掲示されていた。本物の軌道データ（出典記載）で加工してほしい」。

- 元：NASA「Track NASA's Artemis II Mission in Real Time」のページの ZIP（all-artemis-ii-oem-files.zip）の中の `Artemis_II_OEM_2026_04_10_Post-ICPS-Sep-to-EI.asc`（NASA/JSC/FOD/FDO 作成、2026-04-10。ICPS 分離後 4/2 01:57 UTC 〜 大気圏突入 4/10 23:53 UTC。EME2000・UTC）。ページに「物理モデル・アニメーション・可視化・追跡アプリなどを作るのに使える」とある
- 変換：`scripts/artemis2-trajectory.mjs` → `web/tour/artemis2/trajectory.json`（1,403点、gzip 約27KB）。ZIP はリポジトリに入れない
  - 月と太陽の位置は Astronomy Engine で計算。地球の向き（北極・グリニッジ）もその時刻から出す（地球の自転が本物の時刻に合う）
  - 座標は、月の公転面を x-y にした向き
- 確かめたこと：軌道データから計算すると、地球の入り 午後6時42分・地球の出 午後7時22分・日食 午後8時34分〜9時30分（EDT）。NASA の写真の時刻（6時41分・7時22分）と、日食の予定（8時35分から、皆既 54分近く）にそろう。最接近は 22:58 UTC・月面から 6,556 km（NASA の発表は 4,067 マイル＝6,545 km）
- HUD：日本時間の日時と「打ち上げから○日」。「見本」の表示を外した
- 出典：ページの下に、軌道データのページへのリンク
- 見本の道のり（`scripts/artemis2-sample-trajectory.mjs`・`sample-trajectory.json`）は消した

## 見た目と操作の手直し（2026-10-10 オーナーの FB）

- **はじめにオリオンの姿**：乗り込むとき、光る印に近づいて、外からオリオンの姿（イメージの模型：人が乗る部分・サービスモジュール・エンジン・太陽電池パネルの翼）を約8秒見せてから窓の中へ。窓の手前の板が、この翼だとわかるように
- **計器**：数字を大きく（PC 20px・スマホ 15px）、単位とラベルは小さく。日時は見出しの下の1行に
- **画面の下を積み重ねに**：字幕 → （スマホは写真の欄）→ タイムライン → 操作 → 出典、の順に縦に並べて、重ならないように。出典・注意はたたんで「▸ 出典・注意（非公式ファンメイド作品）」を押すと開く
- **見る場所**：窓から・地球から（地球の表面からオリオンを見上げる。オリオンは光る印と「いまここ」）・航路（全体の通り道といまの位置）。「外から」はいったん作ったが、FB2 でボタンをなくした
- **窓の向き**：見る場所の横の丸いボタン（地球・月の絵）。押すと見回した分を戻してその向きへ。場面が変わったら台本の向きに戻る（「窓から」のときだけ出る）
- **帰ってきたとき**：大気に入ったあと、画面がゆっくり暗くなり「地球に、帰ってきました。」「あなたもまた、よい旅を。」。約9秒で、遠くを見る部屋のはじめへ（`../../?from=artemis2`。本体は「観測を開始」を待たずに始めて、部屋を開く。`web/js/main.js`）。「もう一度乗る」も選べる。前の「地球に帰ってきました」の枠（元の航路の画面へ一瞬で戻るもの）はなくした
- 画面：`docs/screenshots/artemis2-tour/`（外から・窓から・地球から・帰ってきたとき）
