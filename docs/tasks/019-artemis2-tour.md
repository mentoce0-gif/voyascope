# タスク019：アルテミス2号に乗ってみる（試作）

きっかけ：オーナー「独自性がないので、より追体験型のモデルを構築してください」「地球〜月を周回しているアルテミスに触れればアルテミスの視点になれるモード（アルテミスが見ていた様子の『ような』視界、航路の通り月の裏側を回り地球へ帰る）。これはワープではなく、数分間アルテミスに搭乗する。画像を数枚参考に、おおよその再現をする」（2026-10-08）。
「3〜4分・写真はリンク」の方向と C22 の依頼文は OK。「月の写真ほんちゃんは NASA のページリンクから。このページはあくまでその画像を参考にしたツアーというていで」（2026-10-08 オーナー）。

## 方針

- 写真はページに載せない。場面ごとに「この場面の本物の写真」の説明と、NASA のページへのリンクを出す（リンクは C22 で公式の URL を確かめてから入れる。いまは押せない）
- 窓の外は、写真を参考にした「〜のような眺め」（コードで描く）。写真そのものではないと、ページの下にいつも書いておく
- 通り道は、本物の軌道データ（C22：Horizons で取れるか・取ってよいか）に差し替えるまで、地球と月の重力から計算した**仮の道**。HUD の日数・距離・速さもこの仮の道から出しているので「見本」と書く
- 日付・時刻・「金星と土星も写っていた」などの事実は、C22 の報告を照合してから入れる。いまの字幕は物理の説明だけ（「月が太陽を隠す」「地球が月に隠れて電波がつながらない」など）
- 置き場所：`web/tour/artemis2/`（`noindex`。地球の画面・遠くを見る部屋からはまだつながない）

## 作ったもの

- `scripts/artemis2-sample-trajectory.mjs`：地球と月（円軌道）の重力で、月の裏側をまわって地球へ戻る道（自由帰還軌道）を探して計算する（RK4）。月にいちばん近いのは約3.2日目・月面から約8,000km、全体で約8.3日。`web/tour/artemis2/sample-trajectory.json`（`sample: true`）に書き出す
- `web/tour/artemis2/`（three.js r128。本体と同じ `vendor/three-r128.min.js` と地球の画像を使う。新しい依存はない）
  - はじめ：通り道の全体を斜め上から見る。光るオリオンに触れる（またはボタン）と、数秒で近づいて乗り込む
  - 乗っているあいだ（約3分半）：出発（地球を振り返る）→ 月へ → 月が近づく → 月の裏側（太陽が月に隠れる・地球が月に隠れて電波がとだえる）→ 地球の出 → 地球へ → 大気に入る。ドラッグで窓の外を見回せる・一時停止・×1/2/4・降りる
  - HUD：飛行日数・地球から・月の表面から・速さ・地球まで光で何秒（すべて仮の道から）
  - スマホ（縦長）では、はじめの絵を縦向き（月が上）にして案内の枠より上に収める。写真の説明が出ているあいだは、字幕をその上へ
- 読み込み量：`config/size-budget.json` に「アルテミス2号ツアー」の組を足した（上限 600KB、いま 536KB。ほとんどが three.js と地球の昼夜の画像で、本体と共通なのでキャッシュが効く）
- 画面：`docs/screenshots/artemis2-tour/`（PC 1440・スマホ 390。はじめ・日食・地球の出）

## C22 のあとにすること

1. 通り道：Horizons で取れて、使い方が JPL に了承をもらった範囲に入るなら、本物の道に差し替える（取り方は「1件ずつ・週1回・連絡先入りの User-Agent」のまま。ミッションが終わった機体なので、取るのは1回でよいはず）。だめなら仮の道のまま「見本」と書き続ける
2. 写真：場面ごとの公式ページの URL・撮った日時・説明を、出典つきで入れる（写真は載せない）
3. 日付：打ち上げ・月にいちばん近づいた日時・着水を、出典つきで HUD とタイムラインに
4. 月の見た目：いまはコードで描いた月（表側の海・裏側のクレーター）。NASA SVS の CGI Moon Kit が使えるなら差し替えを検討（C22 で利用条件を確認）

## 決めてほしいこと

- 入口：遠くを見る部屋（月の停留所）に「光るオリオン」を置いて、触れたらこのページへ、でよいか
- 公開のしかた：C22 の照合が終わるまで `noindex` のまま・リンクなしでよいか
