# タスク004：M1 ── 画面の骨組みと環

ロードマップ：[`docs/roadmap.md`](../roadmap.md) の M1。

## 目的

デザイン案（2026-09-30）の配置に作り替え、機体が増えても破綻しない骨組みにする。
あわせて、`docs/sky-families.md` の「環」を描き、「低軌道は流れ、静止軌道は留まる」が見て分かるようにする。

## 前提

- 優先順位：`RULES.md` ＞ `docs/sky-families.md` ＞ デザイン案
- 表示する機体は今は ISS だけ。M2 で増えても、一覧・パネル・凡例がそのまま使える作りにする
- 色：navy / amber / mint（CLAUDE.md）。家族の色は `sky-families.md` の案（有人＝琥珀、気象・科学＝ティール、測位＝白、通信の帯＝灰、予定＝小さな点）

## 作るもの

1. **配置**（デスクトップ）
   - ヘッダー：ロゴ、サブタイトル、観測時刻、LIVE 表示
   - 左：「注目」一覧（家族のタブ、名前・愛称・高度）。今は ISS 1件
   - 中央：地球
   - 右：詳細パネル（一覧か地球の機体を選ぶと開く）
   - 下：タイムラインと表示の切り替え
2. **タイムライン**
   - −6h〜+24h のつまみ。動かすとその時刻の位置になる
   - 「LIVE」で現在に戻る
   - 再生の速さは残す（×1 / ×60 / ×600）。倍速は環の違いを確かめるための操作
3. **環**
   - 低軌道・中軌道・静止軌道の3本を、地球のまわりに薄い線で描く
   - 半径は比較用（実寸ではない）。画面に「環の半径は比較用。実距離ではない」と必ず出す
   - 機体の高さも同じ比較用の縮尺で描く（ISS は低軌道の環のあたり）
4. **家族ごとの表示切り替え**と凡例1行
5. **詳細パネル**：タブ（概要／滞在／軌道／リンク）。中身は今の銘板カードを分けて使う
   - 軌道タブ：高度・速さ・周期・緯度経度（計算値）と、前後90分の地上軌跡のミニ地図
6. **スマホ**：一覧と詳細は、下から出るシートにする。地球は全画面

## やらないこと

- 顔写真・機体写真・写実的な地球（保留）
- ISS 以外の機体の追加（M2）
- 今夜の通過（M3）、打ち上げ予定（M4）、Starlink の帯（M5）

## 完了条件

- `npm test` と `npm run validate` が通る
- デスクトップとスマホ幅で崩れない（横スクロールなし）
- タイムラインで −6h〜+24h を動かすと ISS が動き、LIVE で戻る
- 環3本とスケールの注記が見える
- 非公式ファンメイドの表記が、起動画面と詳細パネルの両方にある
- PR にスクリーンショットを付ける
