## 方針（2026-10-01 オーナー承認）

- **幅900px以下だけ**を変える。PC版の見た目と操作は変えない
- 環の注記は**いつも出す**（1行に縮める）。「アプリ感」と、実距離ではないという断り書きのため
- 速さはスマホでは**1つのボタン**（押すたびに ×1 → ×60 → ×600）
- 「今夜」は上のバーの**短いボタン**として残す
- 2つの報告は、遡れるように `research/` に残す

## 作るもの（第1弾。小さく1つずつ、毎回スマホ幅とPC幅の画面で確かめる）

1. 下のバーを2段にする
   - 1段目：一時停止・「現在へ」・スライダー・速さ（1ボタン）
   - 2段目：「一覧・観測」・「表示」・「追尾」（機体を選んでいるときだけ）
   - 家族ごとの表示と「環」は「表示」パネルへ（PCでは今の場所のまま）
   - 軌道データの日時・「このアプリについて」は、メニュー（＝このアプリについて）の中にすでにあるので、スマホの下のバーからは外す
   - 軌道データが古いなどの警告は、今までどおり画面に出す
2. 「LIVE」の取り違えをなくす：上は状態（LIVE／+3時間など）、下のボタンはスマホでは「現在へ」。現在を見ているときは控えめ、ずれているときは目立たせる
3. 上のバーを1行にする：ロゴ（下に時刻）・今夜・LIVE・メニュー
4. 押せる範囲を 44×44px 以上にする（再生・現在へ・速さ・一覧・表示・追尾・今夜・メニュー・表示パネルの各行）
5. 環の注記を1行にする（PCは今の文のまま）

## やらないこと

- （第2弾で実施済み）シートの「半分／全部」の2段
- 3段階シート、慣性ドラッグ、長押しなどのジェスチャーだけで動く操作
- UIライブラリの追加、ぼかし・発光の追加
- PC版の配置・文言の変更

## 第2弾（2026-10-01、オーナーの実機での指摘から）

オーナーが iPhone で公開中の版を触って出た3点（スクリーンショットは公開中の古い版）。

| 指摘 | 対応 |
|---|---|
| 詳細をスクロールすると名前と × が消える | 名前と × を上に貼り付ける（裏が透けないよう不透明） |
| つまみ（−）があるのに引けない | つまみを動くようにした。押す・Enter で半分⇄全部、上へ引くと全部、下へ引くと縮める→閉じる。× も残す（WCAG 2.5.7） |
| 家族のフィルターを一覧の中へ。カードが見切れる | スマホでは一覧のタブが地球の表示も絞る形に一本化し、「表示」ボタンをなくした。環は一覧の下へ。一覧を詰め（「注目」の見出しを外す・カードを低く）、一覧は全部の高さで開く |

- 詳細は半分の高さで開き、地球は上のバーとシートの間の真ん中に寄せる（選んだ機体と軌道の線が見える）
- 一覧で全部見えるカード（7機中）：幅390×高さ664で 3 → 6、高さ844で 7
- PC は変えていない：タブは一覧だけ、下のバーのチェックで地球を絞る（位置と大きさも変更前と同じ）
- 横向きのスマホでは、半分の高さの詳細が低い（136px）。つまみで全部にできるので、今回はこのまま

## 第3弾（2026-10-01、マージ後に実機で触って）

オーナーの感想：「機体の真上に行く」「速さの1ボタン」が特によい。下端の機能を1行にしたい。

- 下のバーを1行に：一時停止・スライダー・速さ・一覧（110px → 60px）
- 「現在へ」は上の LIVE 表示が兼ねる。時刻をずらしているときは「↺ +02:03:00」になり、押すと現在に戻る（押せる範囲は44px）。PC の「▶ LIVE」はそのまま
- 「追尾」は詳細の名前の横（× の隣）へ。種類の札は名前の上に小さく置き、名前・英名・NORAD が途中で折れないようにした
- 「一覧・観測」は「一覧」に（観測は上の「今夜」からも開ける）
- スライダーが短くなったので、幅375未満では目盛りを「現在」と「+24h」だけにした
- 幅390×844で、上下の操作部と文字は 185px（22%）→ 135px（16%）
- PC（幅1440・1024）は位置と大きさが変更前と同じ
