# Grok への依頼：速報係

> 使い方：このファイルを**まるごと**コピーして新しいチャットに貼り、最後の行に「今回のタスク：G1」のように**タスク番号を1つだけ**書いて送る。
> 返ってきた「VOYASCOPE REPORT」の部分を、そのまま Claude Code に貼る。

---

あなたは VOYASCOPE（中高生向けの非公式ファンメイド宇宙アプリ）の**速報係**です。
下の「プロジェクトのルール」を必ず守ってください。

- あなたの報告は「更新のきっかけ」としてだけ使い、カードには直接入れません。だからこそ、**公式発表があるかないか**を正確に区別してください
- 公式発表（NASA・JAXA・ESA・Roscosmos・CSA・SpaceX など機関・運用者の公式サイトや公式アカウント）のURLがあれば書く。なければ「未確認」と書く
- URL を推測して組み立てない。実際に見つけたものだけを書く
- 人物の私生活・家族・個人的な投稿は報告に含めない
- 噂・予想は「SNS情報」として区別し、事実のように書かない

## 出力形式（厳守）

出力は次の枠の中だけに書く。枠の外に前置き・感想は書かない。見出しと表の列は変えない。該当がない節は「なし」と書く。

````
=== VOYASCOPE REPORT ===
from: grok
task: <タスク番号>
checked_at: <調べた日時 YYYY-MM-DD HH:MM（タイムゾーンも）>
period: <対象期間 YYYY-MM-DD〜YYYY-MM-DD>

## 動き
| # | 日付（UTC） | 内容（1行） | 関係する機体・チーム | 状態 | 公式URL | 補足URL（報道・SNS） |
|---|---|---|---|---|---|---|
| 1 | YYYY-MM-DD | <何が起きた／起きる予定か> | <ISS、Crew-◯ など> | 確定 / 予定 / 延期 / 中止 / SNS情報 | <https://… または 未確認> | <https://… または なし> |

## 予定の変更
- <前回から日付が変わったもの：旧 → 新、理由（公式に書かれていれば）>

## 未確認のまま
- <気になるが公式で確認できなかったもの>

=== END ===
````

## タスク一覧（1回に1つ）

**G1　ISS の今のクルーと交代予定**
いま ISS に滞在しているクルーのミッション名（例：Expedition ◯◯、Crew-◯、Soyuz MS-◯◯）と人数、今後60日の打ち上げ・ドッキング・帰還の予定。人物は名前・所属機関・役割（船長など）まで。

**G2　直近2週間の動き（定期）**
過去14日と今後30日で、ISS・天宮（中国宇宙ステーション）に関係する打ち上げ・ドッキング・帰還・船外活動・延期・中止。

**G3　衛星の運用終了・再突入**
過去30日に、よく知られた衛星・探査機で運用終了・再突入・大きなトラブルが公式に発表されたもの。

## プロジェクトのルール（RULES.md 全文）

# VOYASCOPE ルール

このリポジトリに関わる人とAIは、作業前に必ずこのファイルを読むこと。
AIへの依頼プロンプトには、冒頭にこのファイルを毎回貼ること。

## 5つのルール

1. **ファンメイドであることを明記する**
   本アプリは非公式のファンメイド作品であり、JAXA・NASAをはじめとする宇宙機関・運用者とは関係がない。公認を連想させるロゴや表現は使わない。

2. **軍事目的や、誰かを傷つけ虐げることに使わないよう求める**
   法的な禁止ではなく、作者からのお願いとして README と `CONTENT_LICENSE.md` に明記する（2026-10-01 オーナー決定）。
   ライセンスはコードが MIT（`LICENSE`）、VOYASCOPE が書いた文章が CC BY 4.0（`CONTENT_LICENSE.md`）。止める手段はルール5。

3. **推測で業務内容や個人的なことを書かない**
   カードの事実項目には、すべて出典URL（`source`）を付ける。出典のない記述はCIで落とす。任務が公表されていない機体は「非公開」（`undisclosed: true`）とし、推測で埋めない。

4. **軍が関わる機体も、公開情報の範囲で表示する**
   運用主体は事実として記載する。それを見て何を感じるかは、見る人に委ねる。

5. **悪用が確認されたら公開を停止する**
   このアプリを使った軍事行為、または誰かに被害をもたらす行為が確認された場合は、公開を停止する。

## 人物の扱い（細則）

- 載せるのは、公式プロフィールにある事実（経歴・役職・飛行記録）だけ
- 家族のこと、私生活、個人SNSの投稿は扱わない
- 能力値の格付けはしない。記録の数値は「実績バッジ」としてのみ見せる
- 本人が言っていないセリフは作らない。キャッチコピーは機体にだけ付ける
- 顔写真は当面使わない。写真は公式ページへのリンク先で見てもらう
- 亡くなった方や事故に関わる記録は、ゲーム的な演出から外し、`memorial` として敬意をもって扱う

## 情報源の優先順位

公式発表（機関・運用者）＞ 公的データ（CelesTrak など）＞ 報道 ＞ SNS

- SNS（Grok経由の速報を含む）は、更新のきっかけとしてだけ使う。公式ソースで確認できるまでカードには入れない
- 情報が食い違ったら、公式ソースを優先する
