# 依頼：VOYASCOPE「遠くを見る部屋」の見た目の試作（1ファイルの HTML）

## どんなアプリか

VOYASCOPE は、地球のまわりの衛星・宇宙船の「いま」を、観測端末風の画面で見る日本語の Web アプリです。対象は中高生で、非公式のファンメイド作品です。

新しく「遠くを見る部屋」を作ります。地球から探査機までの距離が、桁違いに大きいことを体で感じてもらう部屋です。体験の流れは決まっています。今回ほしいのは、**見た目とさわり心地を思い切り強くした試作**です。同じ依頼を別の AI にも出し、スマホで並べて比べます。

帰りに言えることは1つ：**「地球の輪の外は、桁が違う」**

## 体験の流れ（決まっていること。変えない）

1. **光になって飛ぶ**（いちばんの見どころ）
   - 地表の近く（高さ100km）から始まる。上へスワイプ（PC はホイールか ↑ キー）で遠くへ、下へスワイプ（↓ キー）で地球へ戻る
   - 強くはじくほど速く、手を離すと止まっていく
   - 位置は「地球からの距離の桁」（log10 km）で持つ。1回のスワイプで、桁が1つ進むくらい。100km から 1光日の少し先まで
   - 画面の右上：地球からの距離（km の全部の桁）・光年・光で何秒かかるか・いまの速さ
   - 光より速く進んでいるときは「ワープ中：光の◯倍（作り話）」と出す
   - 通り過ぎた場所のカードを出す。文は下の「固定データ」だけを使う
   - 画面の下：物差し。0〜いまの距離を表し、遠くへ行くほど縮尺が変わる。通り過ぎた場所の印は、左へ押しつぶされていく
   - 「光より速く進むのはワープ（作り話）です」を、飛ぶ画面のそばのいつも見えるところに書く
2. **下へスクロールすると「距離のはしご」**
   - 「10万 km〜」「100万 km〜」…「100億 km〜」の段（下へ行くほど10倍遠い）。いちばん上に「地上」の段
   - 名前を押すと、その距離まで飛ぶ（飛ぶ画面に戻って、すっと移動する）
   - 距離のない4機は「いまの距離は準備中」として、はしごの下に名前と1行だけ並べる

## 見た目（ここを思い切り強くしてほしい）

- 方向：ゲームの「観測端末」。暗い紺の宇宙に、アンバーの数字、ミントの線
- 色（変えない）

- 自由にしてよいこと
  - 奥行きのある 3D の飛行、星の流れ、光のにじみ、天体の描き方
  - 通り過ぎる瞬間の演出、ワープの演出
  - カード・物差し・はしごのデザイン
  - 音：最初は消しておき、ボタンで出す。音のファイルは使わず、ブラウザの中で作る音だけ
- 画像のファイルは使わない（外の画像は利用条件の確認が要るため）。天体はコードで描く
- 宇宙機関のロゴ（NASA・JAXA など）は使わない

## 必ず守ること

- **1つの HTML ファイル**。外から読むのは three.js r128（`https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js`）と Google Fonts だけ。three.js を使わず、Canvas や WebGL を直接使ってもよい。ほかのライブラリ・画像・データは読み込まない
- **スマホで滑らかに**：iPhone 12 や Pixel 6 くらいの端末で、1秒60コマが目安
  - 縦長の画面（390×844）がいちばん大事
  - PC（1440×900）でも崩れない
  - 横にスクロールしない
- **動きを減らす設定**（prefers-reduced-motion）では、次のようにする
  - 星を流さない
  - カメラを揺らさない
  - 押した場所へすぐ移る
- **誰でも使える**
  - キーボードでも動かせる（↑↓・PageUp／PageDown・Home で地表へ）
  - 押せるものは 44px 以上
  - 通り過ぎた場所のカードは、読み上げでも分かるようにする
- **書く言葉**：日本語で、中高生が読める言葉にする。上の固定データにない「事実」は書かない（探査機の説明を足さない）
- 画面のどこかに「※非公式ファンメイド作品です。宇宙機関・運用者とは関係ありません」と書く

# VOYASCOPE ルール

このリポジトリに関わる人とAIは、作業前に必ずこのファイルを読むこと。
AIへの依頼プロンプトには、冒頭にこのファイルを毎回貼ること。

## 5つのルール

1. **ファンメイドであることを明記する**
   本アプリは非公式のファンメイド作品であり、JAXA・NASAをはじめとする宇宙機関・運用者とは関係がない。公認を連想させるロゴや表現は使わない。

2. **軍事目的や、誰かを傷つけ虐げることに使わないよう求める**
   法的な禁止ではなく、作者からのお願いとして README と `CONTENT_LICENSE.md` に明記する（2026-10-01 オーナー決定）。
   ライセンスはコードが MIT（`LICENSE`）、VOYASCOPE が書いた文章が CC BY 4.0（`CONTENT_LICENSE.md`）。止める手段はルール5。

3. **推測で業務内容や個人的なことを書かない**
   カードの事実項目には、すべて出典URL（`source`）を付ける。出典のない記述はCIで落とす。任務が公表されていない機体は「非公開」（`undisclosed: true`）とし、推測で埋めない。

4. **軍が関わる機体も、公開情報の範囲で表示する**
   運用主体は事実として記載する。それを見て何を感じるかは、見る人に委ねる。

5. **悪用が確認されたら公開を停止する**
   このアプリを使った軍事行為、または誰かに被害をもたらす行為が確認された場合は、公開を停止する。

## 人物の扱い（細則）

- 載せるのは、公式プロフィールにある事実（経歴・役職・飛行記録）だけ
- 家族のこと、私生活、個人SNSの投稿は扱わない

## 情報源の優先順位

公式発表（機関・運用者）＞ 公的データ（CelesTrak など）＞ 報道 ＞ SNS

- SNS（Grok経由の速報を含む）は、更新のきっかけとしてだけ使う。公式ソースで確認できるまでカードには入れない
- 情報が食い違ったら、公式ソースを優先する
