# 1. リファレンス分析（方向性）

> 注意：Claude Code は動画を再生して見ることができない。以下は、よく知られた作品群の作り方についての一般的な知識からの分析で、特定の作品を1コマずつ確かめたものではない。特定の作品の画面や音を真似しない（著作権・ルール5）。

## 見たジャンルと、効いている作り方

| ジャンル | 例（型として） | テンポ | 構成 | 視覚言語 | 取り入れること |
|---|---|---|---|---|---|
| 科学解説アニメ | フラットな図解系の解説チャンネル | 1カット 3〜6秒。言い切りの一文ごとに絵が変わる | 問い → 小さい例 → スケールを広げる → 意味づけ | 限られた色数、太い輪郭、数字は大きく1つずつ | **数字は1画面に1つ**。スケールを段階的に広げる |
| 宇宙機関の解説映像 | 着陸・打ち上げの解説映像 | 前半は静か、山場で一気に詰める | 「何が起きるか」→「どれだけ難しいか」→「いつ」 | 実写がなくても軌道線・テレメトリ風の文字で緊張感 | **計器表示（等幅の数字・時刻）で「本物のデータ」感** |
| 製品ティーザー（テック） | スマホ・PC の発表映像 | 黒からの立ち上がり、短い言葉、余白 | 1メッセージを言い換えながら3回 → ロゴ → URL | 大きな文字・ゆっくりしたカメラ・最後に静止 | **言葉は短く、余白は多く**。最後は止めて URL を読ませる |
| 映画の予告 | SF 映画の予告 | 3幕：静 → 加速 → 暗転 → タイトル | 日付・場所のテロップで「いま」を固定 | 黒味の挟み込み、文字のトラッキングが広がる | **日付のテロップで始め、暗転でビートを区切る** |

## 今回の方向性（言語化）

- **ひと言**：「観測端末で、宇宙の『いま』を覗く」。ゲーム画面風の計器（mint の線・amber の強調・等幅の数字）で、本物の数字が動く
- **カメラ**：地球のすぐ上（ISS）→ 静止軌道（ひまわり9号）→ 火星へ（MMX）→ いちばん遠く（ボイジャー1号）と、**スケールを4段で広げる**。広げるたびに「ズームアウト＋暗転」
- **テンポ**：1ビート 12〜20秒。中は 3〜5秒ごとに1つの言葉／数字。最後の 10 秒は止めて読ませる
- **音**：今回は入れない（ナレーションは台本だけ用意。音を入れるなら合成した音だけ ＝ X の方針）
- **やらないこと**：実写・写真（機体の写真・人物の顔）・機関のロゴ・ESA の画像。軌道の図は「模式図」と明記する。出典のない数字は出さない
- **対象**：中高生。漢字は控えめ、1行は短く。数字には単位と「約」を付ける
