## 手本：MMX いまどこ（`web/mmx/now/`）の UI から取り入れたこと

| いまどこ の作り | 動画での使い方 |
|---|---|
| 左上の大きな計器の数字（`X+ 2d 19:16:43`）と、小さな英字のラベル | 場面ごとの「いちばん大事な数字」：`NOW 2026-10-22` → `ALT 400 km` → `ALT 35,800 km` → `T+ 00:28:24`（早送り）→ `TARGET PHOBOS` → `RETURN FY2031` → `LIGHT 24:00:00` |
| mint の縦線つきの値（VELOCITY｜33.0） | 計器の2行目（`VELOCITY｜約7.8`、`LIFTOFF｜04:41:03` など） |
| 事象の弧（LIFTOFF → MMX SEP → NOW） | 画面の下の「地球からの距離」の目盛り（EARTH → ISS → HIMAWARI-9 → MARS → VOYAGER 1）。いまの場所が琥珀色の輪で進む。打ち上げの場面には LIFTOFF → MMX SEP の小さな線 |
| 字幕の3段（NOW（…）／太字の2行／補足の中の mint の数字） | すべての字幕を同じ3段に |
| 点線のリーダーつきの太字のタグ | 国際宇宙ステーション・ひまわり9号・種子島・分離・太陽・地球・火星・ボイジャー1号 |
| 丸いピル（ⓘ 模式図・出典・非公式のファンメイド作品） | 右上に常に「非公式のファンメイド作品・出典は最後に」、場面ごとに「模式図」「早送り」「比は本物どおり」 |
| 琥珀色のふちの大きなボタン（REPLAY・ARCHIVE） | 締めの URL（voyascope.org） |

## 音楽

- `scripts/music.mjs` がコードで合成（既存の曲・サンプルは使わない。X の方針「音は合成したものだけ」と同じ）。毎回同じ音になる（決まった乱数）
- D の音階、84 BPM。① 静かな和音ときらめき → ② 和音が進み、計器のような刻み → ③ 打ち上げの前に風の音が上がり、打ち上げで衝撃、そこから鼓動 → ④ 鼓動が消えて広い和音、光が進むあいだ「1時間ごと」に24回の刻み、届いたら鐘 → ⑤ 光が輪を描くあいだ上がっていき、ロゴで長調（Dmaj9）に着地
- きっかけ（打ち上げ・分離・光の出発と到着・輪・ロゴ）は `src/timing.json` から読むので、秒を変えても合う
- 版ごとに作る（`public/music/theme-himawari.wav`・`theme-sky.wav`）。流星群版の「星空」は、刻みが止んで静かな夜の和音、流れ星ごとに「ひゅっ」と高い鈴（時刻は `timing.json` の `meteors`）、ハレー彗星へ引くところで低い和音がふくらむ
- Claude Code は音を聞けないので、スペクトログラムと区間ごとの音量で確かめた（打ち上げ 27.4秒・ロゴ 68.4秒に山。平均 −15.8 dB、ピーク −1 dB）。**聞いた感じの調整は、オーナーの耳で**

## ロゴ

- サイトのロゴ（`web/assets/brand/logo-1200.webp`）を、そのままの大きさで使う
- ロゴの金色の輪の位置・傾きを画素から測り（中心・長さ・−40.7°）、同じ形の輪を、ボイジャー1号へ届いた光のつづきの光の点が描く → 文字が左から現れて本物のロゴに重なる → 輪の上の光が灯る → URL と注記
