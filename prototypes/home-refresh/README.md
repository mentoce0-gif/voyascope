# 入口の見直し（試作）

2026-10-16 に作った試作。本番（`web/`）には入っていない。マージしない（オーナー：「イメージを作ってみて、マージはせず」）。

- 見方：リポジトリの一番上で `python3 -m http.server 8000` → http://localhost:8000/prototypes/home-refresh/ （`?clean` で黄色の注記を消す）
- きっかけ：X の投稿（@amananimates、2026-10-15）で紹介されたデザインの参考集8つ。**オーナー：「あくまで参考に」**。外のサイトのコード・プロンプト・素材（3D アイコン・すりガラスの部品など）は使っていない。考え方だけ
- 中身（番号は画面の注記と同じ）：
  1. ヒーロー：本物の値1つ（ISS のいまの位置・高度・速さ。`web/js/orbit.js` と `web/data/orbits/iss.json` でブラウザの中で計算）＋ボタン1つ「観測を開始」。文字のページへの入口も1行（参考：supahero.io・cta.gallery）
  2. 次の出来事：`web/data/events.json` から、時刻まで公表された次の1件の残り時間と、近い4件。すりガラスはこの1か所だけで、対応しない端末・「透明度を下げる」設定では普通の背景（参考：glass.samasante.com）
  3. スクロールで進むページの「型」：MMX ① 概要（10/22〜）の見本。カードは `curation/probes/mmx.json`・JAXA プレスリリース・プレスキット（C31 照合済み）の文だけ。図は模式図（実際の航路ではない、と画面に書いた）。動きを減らす設定では動かない（参考：scrolltide.co）
  4. フッター：非公式・出典・データの出どころ・ライセンスを1か所に（参考：footer.design）
  5. 部屋のタブ：スマホは画面の下、PC は上の帯（参考：navbar.gallery）
- 入れなかったもの：3D アイコン（観測端末風の見た目と合いにくい・重い）
- 本番にするなら：起動画面（`#boot`）を ① に置きかえる・② ⑤ をいまの部屋の帯や「次の出来事」の列とどうまとめるか・④ を tour/・missions/・mmx/ にも、をオーナーと決めてから
