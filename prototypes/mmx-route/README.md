# MMX の航路のモーショングラフィックス（試作）

2026-10-15 に作った試作。本番（`web/`）には入っていない。

- 見方：リポジトリの一番上で `python3 -m http.server 8000` → http://localhost:8000/prototypes/mmx-route/
  （`?` なしで開くと12秒をくり返す。`window.renderAt(t)` で t 秒の場面を描く）
- 流れ：種子島のピンが光る → MMX（`web/js/far/models.js` の模型）に寄る → 太陽系を見渡す → MMX から先の点線を光が灯していき、火星・フォボスのまわりで止まる
- 試作1（ホーマン軌道の半周）はオーナーに「最短距離すぎる」と言われた → C31（チャッピー）を照合して描き直した（試作2）
- 試作2の航路（どれも公式の事実から計算。JAXA の図は描き写していない）：
  - 地球のそば：打上げ計画書（https://www.jaxa.jp/press/2026/08/files/jaxa20260820-1_01.pdf）の 1回目の燃焼 → 約53分の慣性飛行 → 2回目の燃焼 → 約1時間11分後に火星遷移軌道で分離。東へ上がって地球のまわりを回る形（約1.55π）
  - 太陽のまわり：プレスキット（https://fanfun.jaxa.jp/countdown/mmx_h3f10/files/mmx_press-kit_ja_20260918.pdf）の「往路・復路とも1年弱」「火星圏到着 2027年度」。`route.mjs` が、打ち上げ日の地球と、330日後（**仮**）の火星の位置（astronomy-engine）を結ぶ軌道（ランベルトの解）を出し、`route.json` に書く。結果は太陽のまわりを約221°。分離のときの速さ 11.2 km/s（高度592 km）から出る脱出の余りの速さ約3.3 km/s と、計算の 3.2 km/s がほぼ合う
  - 火星のそば：火星を回る軌道に入り、段階的にフォボスの軌道の高さへ（形は簡略化。投入の回数・軌道の値は 2026 年版で未確認）。フォボスの軌道の半径は火星の半径の 2.76 倍（9,376 km）で、比は本物どおり
  - フォボスのまわり：擬周回軌道（QSO）のイメージ。QSO-H 100×198 km → M → L-A → L-C（ISAS「MMXの軌道計画・軌道決定」）はまだ描き分けていない
- 本物にするときに要るもの：到着の日付（公式は「2027年度」まで）、打ち上げ後の Horizons（-239）の datasheet（計画か追跡か）
- 火星とフォボスの見た目は仮（コードで作った色と形）。フォボスの形は NASA PDS の Gaskell モデルに差し替える予定（タスク020）
- 音（ピンのソナー・フォボスに着いたときの音）は合成したもの。動画を作るときに ffmpeg で付けた
